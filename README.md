# Otto releases

Signed builds of Otto, a private assistant that runs on your own Macs. This repository holds builds only, no source.

**To install:** download `installer-darwin-aarch64--Install-Otto-<version>.dmg` from the
[feed release](https://github.com/adityaJangir-Git-Hub/otto-releases/releases/tag/feed), open it and run Install Otto.
You need an **access code** from the person who gave you Otto; Install Otto asks for it first.

Needs a Mac with Apple silicon and macOS 14 or newer. Every file is signed with Otto's update key and checked before
it is installed. The other files in the release are the parts Install Otto downloads for you.
